    判定ルール

    終値がEMA50より上 / 下+1 / −1中期トレンドの向き
    EMA20がEMA50より上 / 下+1 / −1短期と中期の並び(ゴールデン/デッドクロス)
    MACDヒストグラムが正 / 負+1 / −1勢いの向き
    MACDがシグナル線を上抜け / 下抜け(直近3本)+1 / −1勢いの転換
    RSI 30未満 / 70超+2 / −2売られすぎ / 買われすぎ
    終値がボリンジャーバンド(20, 2σ)下限より下 / 上限より上+1 / −1行き過ぎ

    現物のみで使う前提です。合計 +3 以上で「買い」、+5 以上で「強い買い」、−3 以下で「売却」、その間は「様子見」。「売却」は持っているコインを手放す合図で、持っていないときは「買わずに待つ」という意味です(空売りはしません)。バックテストの買いサインは様子見から買いに変わった足、売却サインは保有中にスコアが −2 以下になった足か、損切りライン(買値 −2×ATR)を割った足です。
